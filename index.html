The website comes second. The problem comes first.

Most projects start by designing pages. Mine start by defining what the website needs to achieve, in eight steps.

See how I build websites →
  1. Define the goalWhat should happen because this website exists?

    What does this website need to accomplish? Not “how many pages?” but “what should happen because this website exists?”

  2. Understand the audienceWho uses it, and what do they need?

    Who is actually using the website? What do they want, what questions do they have, what objections, and what would make them trust the business?

  3. Plan the journeyHow visitors move from arriving to acting.

    Every visit follows a path. Planning it decides what information the site needs, and in what order.

  4. Build the structureThe skeleton comes before the polish.

    The skeleton comes before any visual polish, so the site is organized around the journey.

  5. Design around the goalEvery major decision has a reason.

    Typography, spacing, imagery, color, visual hierarchy and interactions, all chosen on purpose. Every major decision has a reason.

  6. DevelopA real, fast, accessible website.

    The design becomes a real website that is responsive, fast, accessible, functional and maintainable.

  7. Test and improveChecked everywhere before anyone sees it.

    Mobile, desktop, different browsers, forms, links, performance, accessibility and user flows are all checked. Then it is refined.

  8. Launch and measureLive, measured and improved over time.

    The website goes live, but the work doesn't necessarily end there. If appropriate, we measure traffic, inquiries, conversions, engagement and performance, then improve the asset over time.
